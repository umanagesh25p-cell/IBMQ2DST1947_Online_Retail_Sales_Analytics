# Online Retail Sales Analytics

An IBM UG Level 3 Data Science case study focused on analyzing online retail transaction data and developing an interactive sales analytics dashboard using Microsoft Power BI.

## 📌 Project Overview

This project analyzes an online retail transaction dataset to understand sales performance, customer activity, product performance, and geographical sales distribution.

The project includes data preparation and cleaning using Power Query, analytical calculations using DAX, and an interactive Microsoft Power BI dashboard for exploring key business metrics and trends.

## 🎯 Objectives

- Analyze overall online retail sales performance.
- Prepare and clean transactional data for analysis.
- Calculate important sales and customer KPIs.
- Identify revenue trends across time.
- Analyze top-performing products.
- Analyze sales performance across countries.
- Provide interactive filtering and exploration through the Power BI dashboard.
- Generate meaningful business insights from the analyzed data.

## 🛠️ Technologies Used

- **Microsoft Power BI** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and analytical calculations
- **CSV** – Source transactional dataset

## 📊 Dashboard

The Power BI dashboard provides an interactive overview of online retail sales performance.

### Key KPIs

- Total Revenue
- Total Quantity
- Total Orders
- Total Customers
- Average Order Value

### Visualizations

- Revenue Trend
- Revenue by Year
- Top 10 Products by Revenue
- Sales by Country
- Interactive Year-Month filtering
- Stock Code filtering
- Country filtering

The dashboard allows users to explore sales performance through interactive filters and visual analysis.

## 🔄 Data Preparation

The dataset was prepared using Power Query before being used for dashboard development.

The preparation process included:

1. Loading the original retail transaction data.
2. Reviewing data quality.
3. Filtering invalid or irrelevant records.
4. Handling data types.
5. Creating revenue-related calculations.
6. Creating time-based fields such as Year, Month, Month Name, and Year-Month.
7. Preparing the final dataset for Power BI analysis.

## 📈 Key Analysis Areas

The project focuses on:

- Revenue performance
- Sales trends over time
- Product performance
- Customer activity
- Order analysis
- Average order value
- Country-wise sales distribution
